# Contributing to YomiLens

Contributions are welcome through issues and pull requests. For larger changes,
open an issue first to agree on scope. Keep changes focused and explain the
problem, the resulting behavior, and how you checked it.

## Development and checks

Follow the [README](README.md) to build the local dictionary and run the app.
For code changes, run the relevant tests described there and report any tests
that you could not run. Use a physical iPhone when validating camera behavior.

## Licensing and privacy

By submitting a contribution, you agree to license your original contribution
under this project's [MIT License](LICENSE). Only submit material you have the
right to contribute. Preserve existing copyright notices and document any new
third-party dependencies in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
Dictionary data retains its separate upstream terms.

Use original or appropriately licensed test passages and images. Do not include
credentials, personal vocabulary archives, private screenshots, signing files,
or local Xcode user settings. Review the files in your pull request even when
ignore rules are present.
